Fixed Discord Themes by KAZRUTx

Old BetterDiscord themes updated for the current Discord UI. They work with Vencord and BetterDiscord.

How to install

Vencord: click Copy Vencord link, then go to Settings → Vencord → Themes → Online Themes and paste it. The theme updates itself.
BetterDiscord: click Download and put the file in %appdata%\BetterDiscord\themes.

How to install a theme on Vencord/BetterDiscord

Step by step, from downloading the file to seeing the theme in Discord.

Tutorial made by Computrix230
Quick way only for Vencord : on the themes page, click Copy Vencord link, then in Discord go to Settings → Themes → Online Themes and paste it. The theme also updates itself that way. If you'd rather use the file, follow the steps below.

  1. Download the theme

    On the themes page, click Download on the theme you want. You get a file ending with .theme.css.

  2. Open your Discord settings

    Click the gear icon next to your name in the bottom-left corner of Discord.

  3. Go to the Themes tab

    In the left menu, scroll to the Vencord Settings section and click Themes.

  4. Open the themes folder

    Under Local Themes, click Open Themes Folder. On Windows this is %appdata%\Vencord\themes.

  5. Put the theme file in that folder

    Move or copy the downloaded .theme.css file into the folder that just opened. You can keep as many themes there as you want.

  6. Load the new theme

    Go back to Discord and click Load missing Themes. Switching to any other settings tab and back to Themes works too.

  7. Turn it on

    Your themes now appear at the bottom of the Themes tab. Click the switch with the ✕ on the theme you want, and it turns on.

  8. Background image missing? Allow it

    Vencord blocks images from sites it doesn't know. If the theme loads but the background stays empty, go back to the Themes tab. At the top there'll be a red Blocked Resources box: click Allow next to the link.

    A window pops up: tick “I fully trust … and understand the risks”, then click Allow.

  9. Restart discord

    Without a full restart, the image still won't load.

Still not working?

Open an issue on GitHub. Write which theme it is and what looks wrong, and attach a screenshot if you can.
